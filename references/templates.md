# 模板

每套模板是 `templates/<模板名>/` 下的一个目录，生成脚本里用 `Deck("<模板名>")` 选用。
写作规范、配色含义、字号、网格、质检对所有模板都一样，模板只决定版式页的外观、主色和正文区位置。

| 模板名 | 说明 |
|---|---|
| `hust` | 华中科技大学：华科蓝顶栏、校徽、右上角白字章节标签 |

用户没有指定时用 `hust`。

## 目录内容

```
templates/<模板名>/
├── template.pptx    4 页版式：封面、目录、过渡页、内容页（顺序固定）
└── template.json    主色、正文区位置等参数
```

## template.pptx 的要求

Deck 按名字找形状并替换文字，所以下面这些形状必须存在、名字一致（PowerPoint：开始 → 排列 → 选择窗格，双击改名）。
它们在模板里的原文就是占位词，`qa_check.py` 会查生成后有没有残留。

| 页 | 形状名 | 用途 |
|---|---|---|
| 1 封面 | `封面标题` `汇报人` `日期` | 汇报人可以在组合里 |
| 2 目录 | `目录条目` | 一条目录的原型，Deck 按章节数复制并竖排 |
| 3 过渡页 | `章节标题` | 写「一、章节名」 |
| 4 内容页 | `页面标题` `章节标签` | 页面标题写结论句，章节标签写章节名 |

其余形状（顶栏、校徽、标题线、页码）原样复制到每一页，质检时不计入正文。

从别人的 PPT 抽模板时，先删掉形状上的 `p:custDataLst` 和对应的 tags 部件（WPS、iSlide 等插件常留下）：
同一页复制出两份引用同一个标签部件的形状，PowerPoint 会拒绝打开整个文件。

## template.json 字段

长度单位都是 cm，从页面左上角量。

| 字段 | 含义 |
|---|---|
| `title` / `description` | 模板名称和一句外观说明 |
| `tones` | 色调。`primary` 必填，是模板主色（标题条、序号、主要箭头）；也可以改写 `accent`、`error` 或类型色。值为 `"RRGGBB"`，或 `{"base": …, "ink": …, "tint": …}` |
| `body` | 正文区：`x` `y` 为左上角，`w` `h` 为宽高。上边放在内容页标题线下方，左右和标题线对齐 |
| `toc` | 目录条目：第一条左上角 `x` `y`，行距 `pitch`；条目多时行距压缩，使总高不超过 `height` |
| `cover_title` | 封面标题一行可用的宽度 `width` 和最大字号 `max_pt`，标题长时自动缩小字号 |

## 新增一套模板

1. 建目录 `templates/<模板名>/`，放入整理好的 `template.pptx`，照 `templates/hust/template.json` 写参数。
2. 运行检查。它会列出 4 页上每个形状的位置，用来量 `body` 和 `toc`（组合内的形状显示的是组合内坐标）：
   `uv run --no-project --with python-pptx --with lxml python -X utf8 <skill>/scripts/template_check.py <模板名>`
3. 把 `examples/example_deck.py` 复制到草稿目录，改成 `Deck("<模板名>")` 生成一份，跑 `qa_check.py`，
   再用 `render.py --engine powerpoint` 渲染逐页看：目录条目的位置、封面标题的长度、正文是否压到顶栏或页码。
4. 在本文件开头的模板表里加一行。
