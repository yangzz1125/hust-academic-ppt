# 大纲 outline.json

一份汇报一个 `outline.json`，放在汇报目录里（和 `source/`、`figures/`、`build_deck.py` 放在一起）。
`scripts/outline.py` 读它做三件事：`check` 校验并列出只读标题，`wall` 生成便利贴墙，`draft` 生成策划稿。
完整示例是 `examples/microwave/outline.json`，它就是同目录 `build_deck.py` 那份设计稿的策划稿。

## 1. 结构

```json
{
  "meta": {...},
  "parts": [
    {"title": "章节名", "pages": [{...}, {...}]},
    {"title": "总结", "toc": false, "pages": [{...}]}
  ]
}
```

页码按 封面 → 目录 →（过渡页 → 内容页）× 章 数，和 `draft` 生成的 pptx、便利贴上的「第 n 页」一致，
用户说「第 7 页」时三处对得上。

## 2. meta

| 字段 | 必填 | 含义 |
|---|---|---|
| `title` `presenter` `date` | 是 | 封面标题、汇报人（最多约 8 个汉字）、日期（「2026年10月14日」） |
| `template` | | 模板名，默认 `hust` |
| `occasion` `audience` `minutes` | | 场合、听众、时长（分钟）：需求调研的结论，显示在便利贴墙顶部 |
| `thesis` | | 整份汇报要听众接受的那一个结论 |

## 3. 章节 parts

| 字段 | 必填 | 含义 |
|---|---|---|
| `title` | 是 | 章节名，写进目录、过渡页和内容页右上角的章节标签 |
| `toc` | | 默认 `true`。`false` 时不进目录、不加过渡页，用于开头的引入页和最后的总结页 |
| `pages` | 是 | 内容页列表 |

## 4. 内容页 pages

| 字段 | 必填 | 含义 |
|---|---|---|
| `title` | 是 | 结论句标题（`content_rules.md` 第 2 节） |
| `blocks` | 是 | 正文分块，见第 5 节 |
| `composition` | | 一句话写构图：主角是什么、怎么摆，或命名页型名（「引线标注：照片居中，两侧各三块部件说明」） |
| `cols` | | 这一页网格的列数，默认 12；五步并列用 5，三步用 3 |
| `bottombar` | | 页底总结条 `["标签", "一句话"]`，有它时网格下边上移 |
| `notes` | | 口播要点，`draft` 写进备注 |
| `sources` | | 这一页证据的出处（`source/` 下的文件），设计稿质检时用 |

## 5. 块 blocks

```json
{"grid": [8, 0, 4, 6], "kind": "卡片", "header": "工作过程", "content": ["要点一", "要点二"]}
```

| 字段 | 必填 | 含义 |
|---|---|---|
| `grid` | 是 | `[列, 行, 占几列, 占几行]`，和设计稿里 `Grid().box(...)` 的参数相同；行从上往下数，共 6 行 |
| `kind` | 是 | 块的类型，见下表 |
| `header` | | 块的标题。文字块有它时画成带浅底标题条的卡片；图表类块有它时外面套一张卡片 |
| `content` | 是 | 字符串或字符串列表。文字块写要点（设计稿再写足）；图表类块写放什么、从哪来 |
| `cols` | | 这一块用的网格列数，默认取页面的 `cols`。一页上半五列、下半十二列时用（如示例第 7 页） |

| kind | 策划稿里画成 | 设计稿里通常用 |
|---|---|---|
| `卡片` | 白底卡片 + 要点 | `card()` + `bullets()` |
| `文字` | 要点（有 `header` 时套卡片） | `tint()`、`text()`、`keynum()` |
| `图片` | 虚线占位框 | `web_figure()`、`figure()`、`gallery()`、`strip()` |
| `图表` | 虚线占位框 | `chart()` |
| `表格` | 虚线占位框 | `table()` |
| `节点图` | 虚线占位框 | `node()`、`link()`、原生示意图、时间线 |
| `公式` | 虚线占位框 | `P(...)` + `var()`、`formula()` |
| `代码` | 虚线占位框 | `snippet()` |

块不能越出网格，也不能互相重叠，`check` 会报错并指出哪一页哪一块。
引线标注、时间线这类块位置不规整的页，按大致区域分块即可，策划稿只需看出主角在哪、占多大。

## 6. 提示

`check` 和便利贴墙会标出：

- 标题按 24pt 估算一行放不下；
- 构图（各块的位置和尺寸）和上一页相同；
- 没写口播要点。

这些是提示，不阻止生成。
