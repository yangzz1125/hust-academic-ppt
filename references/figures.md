# 取图与嵌图

写网页初稿前读：初稿就要放真图。页面上的表格、卡片、分组框原生画；图都从这里取。

## 1. 放什么图

本节都是用户明确要求过的。

### 证据顺序：原图当主角

用户拿同学的会议 PPT 对比后要求的：同学每页 3–25 张研究原图，图占页面 25–44%；我们的答辩稿准备了 36 张图只用了 8 张，
多数页只有文字和自己画的方框，用户评价「太烂了」。证据按这个顺序找：

1. **本工作的结果图和方法图**：报告、论文 PDF、LaTeX 项目 `figures/*.pdf` 里的图（第 2 节）。
2. **文献原图**：讲别人工作时放对方论文里的图（第 6 节）。
3. **实物照片**：器件、装置、现象（第 5 节）。能用照片就不用方框代替实物（「明明可以用实际的图片，却偏偏用框框来表示」），
   步骤、时间线的节点也配照片（`examples/microwave/` 的能量路径五步、时间线）。
4. **原生图表**：只有数据、没有现成的图时用 `chart()` 画，数据能在 PowerPoint 里改。
5. **原生示意**：前四种都没有、又必须讲清的关系才画——抽象关系、场和波的分布、受力和热量的走向。

报告和论文里已有的示意图、框架图、流程图直接放原图，不重画成方框。能证明工作真实存在的材料嵌成图片：
数据片段（JSON）、代码、终端输出、软件截图、数据图、LaTeX 公式（第 3、4 节），只放本次汇报这一阶段的；不用 AI 生图。

### 图要放多少

- 除研究问题、总结和下一步外，每张内容页至少一张图或图表，占正文区两成以上；
  `qa_check.py` 会报没图和图太小的页，`--figures figures/` 列出取了没用上的图。
- **列举的每一项配一张图**（用户指出过「图不够丰富」）：应用领域、工艺步骤、影响因素、器件部件、信号种类、几类方法，
  每一项一张图，不写成一列文字。用户认可的开题 PPT（张楠）讲「半导体应用」放了芯片、晶圆、处理器 4 张照片，
  讲「光电响应」放了放电照片、光谱、V–I 波形各一张；我们的答辩稿把「微电子制造、等离子体医学、能源化工」写成了三行字。
- **背景章每页 3–4 张以上**（那份开题 PPT 背景 4 页共 27 张），**研究现状每页 6–12 张**（下一小节）。
- **切页时列图单**：`outline.json` 每页的 `figures` 写要放的图和来源（`outline.md` 第 2 节），先把图找齐再写初稿。
  论文图写到论文、PDF 页码、图号，以及裁图时要保留的坐标轴、图例、实验条件
  （「Dias2023.pdf 第 7 页图 4b，保留横轴气压和图例」），裁图和复核都照这一条做。

### 文献图是展示用的

用户明确说过：「展示自己的工作量，而不是让别人看懂」。研究现状、综述页放文献原图，是让听众看到调研覆盖了哪些工作、
各家做到了哪一步，不指望听众在台下读懂图里的细节：

- 每项放 3–4 张（装置照片、方法示意、结果曲线搭配），图可以小到图里的字看不清，一页九张十张都正常；
  解读写在图下「调节变量」「结果」这类一两行字里，不靠听众读图。
- 只有要对着图逐项讲的（本工作的结果、引线标注页、公式拆解），才要求图大到看得清。
- 手头的图不够时去找论文的公开版本取更多图：arXiv、机构仓库（infoscience、OSTI 等）的 PDF 用第 6 节裁，
  期刊网页上的图用 `fetch_image.py add`（Nature 系列的图地址是
  `media.springernature.com/full/springer-static/image/art%3A<DOI 转义>/MediaObjects/<文章号>_Fig<n>_HTML.png`）。
- **严格材料边界例外**（论文精读、文献汇报，`meta.strict = true`，`content_rules.md` 第 1 节）：图只取材料清单里
  核心、补充论文的原图或原始数据，按清单写明的页码裁；不上网找图，不画描述性插图，「仅背景」的论文不取图。
  图不够撑起某一页时写进 `todo` 问用户。

### 照片和网上的图

背景介绍、原理讲解可以用网上的图，任何来源都行（严格材料边界除外）：实物和器件照片、实验装置、自然现象、历史照片，
以及原生形状难画的示意图（场线分布、波的传播、器件剖面）。照片要能证明标题或配合讲解（对着编号讲部件），只起装饰作用的不放。

### 图注、出处和参考文献

- **图下写图注，页面上不写出处**（组会、课程汇报这类场合）：网图、论文里的图和数据都不在页上标引文。
  图注写图里是什么、图上标号的含义，一行为宜，不写结论（结论在要点句里）。只写图上看得出来或材料里有的内容，
  不凭常识补充（照片看不出「四壁是金属」就不写）。网图的来源和许可只记在图片旁的 `.json` 里。
- **开题、答辩讲到别人工作时只标「[n]」**（面板标签「贝叶斯优化 [7]」、图注或正文里），
  全文条目统一放在末尾参考文献附录页（`content_rules.md` 第 6 节）。

### 其他

- **图由 Claude 挑**：自己检查后直接放，不用先给用户挑。
- **重做别人的 PPT 先导出原稿全部图**：图片对象、形状和表格单元格的图片填充、SVG 里嵌的位图都要导出，
  逐页放回去；原稿的图明显比新稿多就是做砍了。

## 2. 本工作的图：从报告、论文和 LaTeX 项目导出

用户给了报告、论文或 LaTeX 项目时，先把里面的图全部导出到 `figures/`，再写初稿：

- **LaTeX 项目里的 PDF 图**（`figures/*.pdf`，矢量）：`pdftoppm -r 300 -png -singlefile fig.pdf figures/fig`，
  或用 pymupdf 按 300dpi 导出；透明底的图用 pymupdf 导出（`alpha=True`）。
- **位图**（`figures/*.png`、`*.jpg`）：直接复制。
- **只有编译好的 PDF**（报告、论文）：用第 6 节的 `pdf_figure.py list` 找到每张图的位置，`crop` 裁出来。
- 数据图上的字放进页面后小于 12pt 时，用作者的绘图脚本（如 `make_figures.py`）放大字号重出一版，不在 PPT 里硬放大。
- 导出后按图号命名（`rep_fig3.png`），在生成脚本开头的注释里记下每张图怎么来的。

## 3. 代码、JSON、终端输出

```bash
uv run --no-project --with pillow --with pygments --with fonttools python -X utf8 <skill>/scripts/snippet.py \
    片段.json 片段.png --kind json|python|terminal --title "文件名（节选）" --pt 14
```

- 字号用 13–14pt（放进 PPT 后就是这个字号）；一行放不下就把片段改窄（节选、换行），不缩小字号。
- terminal 模式里以 # 开头的行是灰色注释，含「失败 / 错误」的行标红。
- 报错示例要真实运行得到（例如改坏一份副本再加载），不手写。原文和渲染命令记在生成脚本里。
- 用 `c.snippet(png, anchor, x, y)` 按原尺寸放入；箭头用返回值的 `line_y(k)` 对准第 k 行，不按像素手算。

## 4. 公式

- 短式子写成可编辑文字：`P(R("∇ × ", latin="Cambria Math"), *var("E"), " = …")`，变量用 `var()`（斜体、可带下标）。
- 分式、积分等复杂公式用 LaTeX standalone 编译后 `pdftoppm -r 600 -png -singlefile` 导出，再用 `c.formula(png, x, y)` 放入。

## 5. 网上的图

网上的图都可以用，按哪张最合适来选，不受来源限制。讲到器件、设备、部件、实验装置、历史事件时先找照片，
找不到再考虑原生示意：

- **Wikimedia Commons**：用 `search` / `get` 直接检索下载，作者和许可自动记下，SVG 可取 PNG 渲染图。
  常用词可用中文（「磁控管」「微波炉」），专业术语用英文更准（「驻波」搜不准，`standing wave` 准）；
  要图上是中文标注的示意图，关键词后加 `intitle:zh`（如 `"electromagnetic spectrum intitle:zh"`）。
- **其他网站**（百度图片、百度百科、公众号、博客、论文、厂商页面等）：百度对脚本直接访问返回安全验证，
  所以先用 WebSearch / WebFetch 或浏览器（Claude in Chrome）找到图片直链和所在网页，再用 `add` 下载登记。

```bash
F="uv run --no-project --with pillow python -X utf8 <skill>/scripts/fetch_image.py"
$F search "magnetron" --kind photo          # --kind diagram 只找 SVG 示意图
$F get "File:Magnetron detail.jpg" <汇报目录>/figures --name magnetron
$F add <图片直链> <汇报目录>/figures --name xxx --title 题名 --source "百度百科" --page <图片所在网页> [--author 作者]
```

- `add` 用浏览器 UA 请求，并把 `--page` 作为 Referer（公众号、百科图床会查防盗链），WebP 自动转成 PNG。
  报「返回的不是图片」时，多半是防盗链或验证页：补上 `--page`，或在浏览器里打开图片拿原图直链。
- **公众号**：文章页 `mp.weixin.qq.com/s/...` 能直接抓，正文图片是 `data-src="https://mmbiz.qpic.cn/..."`（`&amp;` 还原成 `&`）。
  `--page` 填这篇文章的链接，或者不填；填别的网站会拿到「此图片来自微信公众平台 未经允许不可引用」的 140×140 占位图。
  图片地址里的 `wx_fmt=gif` 是动图，PPT 里能正常播放。
- `add` 会打印下载到的像素尺寸，尺寸异常小时先用 Read 看是不是占位图。
- `get` / `add` 在图片旁写同名 `.json`，记下作者、来源、许可（其他网站没写许可的留空，作者不明写「佚名」）；
  `reference` 是 GB/T 7714-2015 的 [EB/OL] 条目，
  需要参考文献页时直接用它。用 `c.web_figure(path, box, 图注)` 放入，缺 `.json` 会报错。
- 一次连续取十几张图后 Commons 会返回 HTTP 429，脚本会按 Retry-After 等待后重试；批量取图时每张之间停几秒。
- 取图后用 Read 看一遍：内容对不对、有没有裁掉的标注、图上的字放进页面后是否太小、有没有水印。有缺陷就换图，
  或者改用原生示意图、`chart()` 重画（`examples/microwave/` 的水分子示意和驻波曲线就是这样来的）。
- **图上自带的编号写进图注**：`get` 会打印 Commons 的描述，里面常有「1) cathode 2) anode」这样的编号含义，
  图注按图上的编号全部列出（如「磁控管剖面：1 阴极 2 阳极 3 永磁体……」），讲解也按这个编号来。
- 图片按放置尺寸至少 150dpi（`qa_check.py` 会查），不够就换大图或放小。示意图优先选 SVG，可以取任意宽度。
- 图里的英文标注（如 E、H、λ）听众能看懂就保留；需要中文时在图旁用原生文字加注，不改原图。

## 6. 论文里的图

从 PDF 按 300dpi 裁出图，不截整页。要对着讲的图裁到要讲的子图；只作展示的文献图（第 1 节）可以整张多面板图缩小放，
也可以把一张组图拆成几张，和别的图拼成一组。

```bash
P="uv run --no-project --with pymupdf --with pillow python -X utf8 <skill>/scripts/pdf_figure.py"
$P list 论文.pdf                                   # 各页图注（Fig. n）和位图的位置，坐标是页面比例
$P preview 论文.pdf 5 <scratchpad>/p5.png           # 带 10% 网格的整页预览，Read 看图读出裁切范围
$P crop 论文.pdf 5 <汇报目录>/figures/fig3b.png --box 0.12,0.54,0.82,0.89
```

- 裁切命令记在生成脚本里，换范围时改命令重跑。不裁论文原图注，图注在 PPT 里用 `figure(..., caption=)` 重新写
  （「论文图 3b：……」）。
- **裁切质检**（Read 看裁出的图，每项都要满足，缺一项就是缺陷，不是可以接受的取舍）：
  坐标轴、轴标题、刻度、图例、色标、比例尺都在；讲解要提到的子图字母（a、b、c）在；方法名、分组名可读；
  四周留了余量；没有带进相邻图的边角（上一张图的底边、旁边子图的坐标轴）。
  要对着讲的图，按计划尺寸放进页面后最小的字还要不小于 12pt；只作展示的文献图不查这一项。
- 修法依次是：扩大裁切范围、拆成两页、整页只放这张图、简单的柱图和表格用 `chart()` / `table()` 按论文里的数值重画。
